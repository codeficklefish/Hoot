What it reads

A filename is often the least informative thing about a file.

Hoot opens documents, spreadsheets and archives, and reads the words in photos and scans — so a file whose name says nothing still says what it is.

Documents

PDFs, Word files and plain text. A book's title page identifies it even when the filename is a hash.

Spreadsheets

A sheet called open case summary.xlsx turns out to hold tax records. It goes to Finance, not to a folder named after its file type.

Archives

A zip is judged by what it contains. One holding a single installer is software; one holding a project's source is that project.

Photos and scans

Text is read out of images on your Mac. A scanned receipt with no text layer is still recognised as a receipt.

Your existing folders

A folder you called Books is a description of what you mean by books — better than any general rule about file types.

An on-device model

Apple Intelligence groups related files and suggests folders. Without it, Hoot falls back to filename rules and says so.

Before anything moves

Nothing moves until you say so.

An app that rearranges your files has to earn that. Hoot shows every suggestion, tells you what it based each one on, and can put it all back.

You approve every move

Suggestions arrive in a review window. Untick anything you disagree with, or open a file to see the evidence behind the decision.

Every move is reversible

Each batch is logged and can be undone, today or next week. Files go back exactly where they came from, and undo refuses to overwrite anything that has since taken their place.

It never deletes anything

Superseded versions are moved aside rather than removed, and a file already at the destination is never overwritten — the new arrival gets a free name instead.

Confidence comes from independent signals agreeing — the filename, the text inside the file, and the on-device model — never from the model rating its own answer. When Hoot is unsure, it says so and leaves the file where it is.

Corrections

It learns your filing, not someone else's.

Drag a file to a different folder and Hoot remembers. Correct a few invoices into Finance, and the next one — from a client you have never had — goes there by itself.

Privacy

Hoot cannot reach the network.

Not “does not” — cannot. macOS requires an app to hold the network entitlement before it may open an outgoing connection. Hoot ships without one. These are the only permissions it has:

  • com.apple.security.app-sandbox
  • com.apple.security.files.user-selected.read-write
  • com.apple.security.files.bookmarks.app-scope

And the source is public, so you can check — every line of it.

One folder, chosen by you

macOS grants access to that folder alone. Hoot has no way to see anything else on your Mac.

No account, no server

No sign-in, no analytics, no telemetry, no crash reporting. There is no networking code in the app at all, and no third-party dependencies.

The model runs here

Apple Intelligence runs on your Mac. Prefer not to use it? Choose filename rules and no model is involved.
