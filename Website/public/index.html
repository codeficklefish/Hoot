Two ways to sort

By what they’re about, or by what they are.

Switch between them in the menu bar popover or in Settings, where each mode is shown as the folders it would produce rather than described.

By meaning

Folders named after subjects. It reads inside files and takes a few seconds.

By type

Folders named after what files are. It decides from the filename alone, so it is instant, never opens a file, and reaches no model at all.

ScreenshotsImages PDFsSpreadsheets VideosAudio ArchivesInstallers

Screenshots get their own folder because nothing but the name separates one from a photograph. Files whose type Hoot doesn’t recognise are left where they are — a junk drawer named by the app is worse than not moving them.

Renaming

A name that says nothing is only half the problem.

Moving 32131231231.pdf to the right folder still leaves you unable to find it. Hoot proposes a real name, taken only from text actually read out of the file.

Every rename is shown before it happens, can be refused on its own, and is put back by undo.

Opens a folder where it stands

Its contents appear indented underneath and the list you were looking at stays exactly where it was. On a file, the same panel the Finder opens. Press it again and it shuts.

Never takes your focus

Pointing at the notch doesn’t take keyboard focus, which is what lets you open it mid-sentence. Clicking a row does, because a spacebar can only reach a window that has it.

Three folders, by name

Three, because three names fit across the panel at a size you can still read — a tab shortened to Docu… has stopped saying which folder it is.

Hoot only ever reads these folders — it never moves, renames or deletes anything in them. That is what lets there be several, while the one folder it organises stays one. Needs a display with a notch; everywhere else the menu bar popover is the whole interface.

Before anything moves

Nothing moves until you say so.

An app that rearranges your files has to earn that. Hoot shows every suggestion, tells you what it based each one on, and can put it all back.

You approve every move

Suggestions arrive in a review window. Untick anything you disagree with, or hold a row to preview the file the way the Finder does — the filename is usually what failed to say what it is.

Every move is reversible

Each batch is logged and can be undone, today or next week. Files go back exactly where they came from, and undo refuses to overwrite anything that has since taken their place.

It never deletes anything

Superseded versions are moved aside rather than removed, and a file already at the destination is never overwritten — the new arrival gets a free name instead.

Confidence comes from independent signals agreeing — your corrections, your existing folders, the text inside the file, and the on-device model — never from the model rating its own answer. When Hoot is unsure, it says so and leaves the file where it is.

Corrections

Drag a file to a different folder and Hoot remembers. Correct a few invoices into Finance, and the next one — from a client you have never had — goes there by itself.

Privacy

Hoot cannot reach the network.

Not “does not” — cannot. macOS requires an app to hold the network entitlement before it may open an outgoing connection. Hoot ships without one. These are the only permissions it has:

  • com.apple.security.app-sandbox
  • com.apple.security.files.user-selected.read-write
  • com.apple.security.files.bookmarks.app-scope

And the source is public, so you can check — every line of it.

One folder organised, any number read

Hoot organises the one folder you choose. The shelf shows any number you add and only ever reads them — it never moves, renames or deletes anything there. That asymmetry is what makes several folders safe.

No account, no server

No sign-in, no analytics, no telemetry, no crash reporting. There is no networking code in the app at all, and no third-party dependencies.

The model runs here

Apple Intelligence runs on your Mac. Prefer not to use it? Choose filename rules and no model is involved.

Choosing a folder is what grants access to it, and nothing else. Adding folders to the shelf needed no new entitlement — the two above already meant “whatever you pick, however many times”.
