Files sorted by meaning, not by extension.

Hoot watches a folder and works out what belongs together. A boarding pass, a hotel booking and an itinerary become one trip folder — not three piles sorted by file type.

That photo has no readable name. Hoot read the words in the picture — a café menu — and filed it under Food.

It reads what is inside.

A filename is often the least informative thing about a file. Hoot opens documents, spreadsheets and archives, and reads the words in photos and scans, so a file with a meaningless name still says what it is.

Documents

PDFs, Word files and text. A book's title page identifies it even when the filename is a hash.

Spreadsheets

A sheet called open case summary.xlsx turns out to hold tax records. It goes to Finance, not to a folder named after its file type.

Archives

A zip is judged by what it contains. One holding a single installer is software; one holding a project's source is that project.

Photos and scans

Text is read out of images. A scanned receipt with no text layer is still recognised as a receipt.

Nothing moves until you say so.

An app that rearranges your files has to earn that. Hoot shows you every suggestion, tells you what it based each one on, and can put everything back.

You approve every move

Suggestions arrive in a review window. Untick anything you disagree with, or open a file to see the evidence behind it.

Every move is reversible

Each batch is logged and can be undone, today or next week. Files go back exactly where they came from.

It never deletes anything

Superseded versions are moved aside rather than removed, and a file already at the destination is never overwritten.

Confidence comes from independent signals agreeing — the filename, the text inside the file, and the on-device model — never from the model rating its own answer. When Hoot is unsure, it says so and leaves the file alone.

It learns your filing, not someone else's.

Drag a file to a different folder and Hoot remembers. Correct a few invoices into Finance and the next one from a client you have never had goes there by itself.

It also studies the folders you already made. A folder you called Books is a description of what you mean by books — far better than any general rule about file types.

There is no network code in this app.

Not “we do not sell your data” — there is nothing in Hoot that can send anything anywhere. The model runs on your Mac, and no part of the app knows how to reach a network.

No account, no server

Nothing to sign up for. Hoot never asks who you are.

The model is on your Mac

Apple's on-device model does the thinking. Your files are not uploaded to be understood.

Sandboxed

Hoot can reach the one folder you choose, and nothing else on your Mac.

Cloud files stay in the cloud

Files stored online but not downloaded are never opened, so Hoot cannot start a download you did not ask for.

Point it at your Downloads folder.

It sits in the menu bar and stays quiet until there is something worth showing you.
